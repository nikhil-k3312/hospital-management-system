AHP questionnaire: importance of sign-in signals (5-10 respondents: hospital IT,
security staff, and clinicians who use the system)
===============================================================================

Context: when someone signs in to the hospital system with the correct password,
the system looks at four signals to judge whether it is really that person.

  L  Location agreement - does the place the internet address points to match
     the place the browser reports?
  D  Trusted device     - is the sign-in from a browser this person enrolled before?
  T  Time of day        - is the sign-in during normal duty hours?
  N  Network            - is it from the hospital network or a network this person
     used before?

For each pair, answer: "Which signal is MORE important for telling a genuine
sign-in from an attacker, and by how much?"

  1 = equally important     3 = moderately more     5 = strongly more
  7 = very strongly more    9 = extremely more      (2, 4, 6, 8 = in between)

Write the number if the FIRST signal is more important, or 1/number if the
SECOND is more important (e.g. 1/3).

  1. L vs D : ____        4. D vs T : ____
  2. L vs T : ____        5. D vs N : ____
  3. L vs N : ____        6. T vs N : ____

Name / role (kept confidential, used only to label the row): ______________

Enter each respondent as one row in responses.csv and run:  python ahp.py responses.csv
A consistency ratio (CR) above 0.10 means that respondent's answers contradict
each other; ask them to look again at their answers.
Note: if your institute requires ethics approval for staff surveys, obtain it first.
